# Model binary policy

The Stage 3/5 MediaPipe Pose Landmarker uses `pose_landmarker_full.task`. This binary is **not** committed. In the NUC project it resides at `~/drone_stage3_pose/models/pose_landmarker_full.task` and can be obtained through the model acquisition procedure documented in `stage3_pose/README.md` / `stage3_pose/STAGE3_POSE_RESEARCH.md`. Before runtime use, verify SHA-256:

`4eaa5eb7a98365221087693fcc286334cf0858e2eb6e15b506aa4a7ecdcec4ad`

Do not substitute a different model silently. No OSNet weight is bundled or claimed to be in Stage 5 runtime.
